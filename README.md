# STROYMA - Интернет-магазин строительных материалов

## О проекте

STROYMA - это веб-сайт для магазина строительных материалов, разработанный на Django. Система позволяет управлять каталогом товаров, обработкой заказов, услугами и взаимодействием с клиентами.

## Технологии

- Python 3.12+
- Django 5.2.17 (LTS)
- PostgreSQL
- Redis (кеш, сессии `cached_db`, ratelimit/axes — при заданном `REDIS_URL`)
- Docker / Docker Compose (рекомендуемый деплой)
- Gunicorn + Nginx (внутри Compose), Caddy для HTTPS на VPS
- Bootstrap (фронтенд)
- Jazzmin (админ-панель)

## Установка и настройка

### Деплой на VPS (Linux) через Docker Compose

Полная пошаговая инструкция с командами установки Docker, настройки DNS и `.env`, переноса локальной PostgreSQL 17 и `media/`, запуска, проверок, бэкапов, восстановления и обновления: **[deploy/DEPLOY_VPS.md](deploy/DEPLOY_VPS.md)**.

Продакшен-стек: PostgreSQL 17, Redis, Django/Gunicorn, отдельный worker для уведомлений о заказах, Nginx и Caddy для HTTPS. `web` автоматически запускает миграции и `collectstatic`. Заказ фиксирует цену и название товара на момент оформления и проверяет остаток в транзакции. Онлайн-оплата на сайте не предусмотрена: менеджер подтверждает заказ и согласует расчёт.

Миграция `products.0016` заполняет цену старых позиций текущей ценой товара: историческая цена до этой миграции в БД не хранилась. Перед обновлением действующего сайта сделайте бэкап. Миграция `services.0007` удаляет записи видеороликов услуг из БД; файлы остаются в `media/` до отдельной проверки и очистки.

### Разработка через Docker Compose

С тем же `.env` можно запустить локальный HTTP-режим: override включает `DEBUG=True`, выставляет локальные хосты и отключает индексацию. Nginx слушает только `127.0.0.1:8080` (порт можно изменить через `HTTP_PORT`).

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build
```

Откройте `http://127.0.0.1:8080`. Для команд `exec` используйте тот же набор файлов `-f`.

При локальном запуске без продакшен-Compose отдельно запустите worker: `python manage.py process_order_notifications --loop`. Без него заказы сохраняются, а письма остаются в очереди БД до запуска команды.

**Перенос данных из локального PostgreSQL** на VPS вместе с `media/` — см. [шаг 4 инструкции VPS](deploy/DEPLOY_VPS.md#4-данные-выберите-один-вариант).

**Резервное копирование на VPS** (дамп БД + архив `media/`):

```bash
chmod +x deploy/backup.sh deploy/restore.sh
bash deploy/backup.sh
```

Восстановление БД из `pg_*.sql.gz`: `bash deploy/restore.sh backups/pg_....sql.gz`; соответствующий архив `media_*.tgz` распаковывается отдельно. Порядок остановки сайта и восстановления описан в [инструкции VPS](deploy/DEPLOY_VPS.md#6-бэкапы-и-восстановление).

### Локальная разработка без Docker

**Требования:** Python 3.12+, PostgreSQL, Git. Опционально Redis (`REDIS_URL`) — иначе используется LocMemCache.

1. **Клонирование репозитория**
```bash
git clone <URL_репозитория>
cd stroyma_website
```

2. **Виртуальное окружение и зависимости**
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate
pip install -r requirements.txt
```

3. **Переменные окружения** — скопируйте `.env.example` в `.env` и заполните `SECRET_KEY`, `DB_*`, SMTP и при необходимости `REDIS_URL=redis://127.0.0.1:6379/1`.

4. **База данных** — создайте БД и пользователя в PostgreSQL, затем:
```bash
python manage.py migrate
python manage.py createsuperuser
```

5. **Запуск dev-сервера**
```bash
python manage.py runserver
```

Сайт: http://127.0.0.1:8000 , админка: http://127.0.0.1:8000/management-stroyma-7x4/ (или путь из `ADMIN_URL`).

### Импорт цветов/текстур фасада и обслуживание медиа

- Импорт из `ceresit_colors_textures.json`: `python manage.py import_colors_textures` (идемпотентно; обновление существующих: `--update`).
- Удаление файлов в `media/`, на которые не ссылается ни одно поле `FileField` (сначала проверьте список в dry-run): `python manage.py cleanup_media`, затем `python manage.py cleanup_media --apply`.
- Конвертация существующих JPG/PNG в WebP (с бэкапом в `media_backup/` при `--apply`): `python manage.py optimize_media`, затем `python manage.py optimize_media --apply`. Исходные файлы остаются до отдельной проверки и очистки через `cleanup_media`.

Новые загрузки изображений в админке автоматически конвертируются в WebP (качество 90), кроме GIF.

## Структура проекта

- **accounts**: Управление пользователями и профилями
- **products**: Управление товарами, категориями, заказами и корзиной
- **services**: Управление услугами и фотографиями услуг
- **templates**: Шаблоны сайта
- **static**: Статические файлы (CSS, JS, изображения)
- **media**: Загруженные пользователями файлы

## Функционал сайта

### Каталог товаров

- Иерархические категории товаров (с использованием MPTT)
- Детальная страница товара с фотографиями, описанием и ценой
- Фильтрация товаров по категориям, цене и другим параметрам
- Поиск товаров

### Корзина и заказы

- Добавление товаров в корзину с указанием количества
- Просмотр и редактирование корзины
- Оформление заказа с указанием данных доставки
- Отслеживание статуса заказа
- История заказов в личном кабинете

### Услуги

- Каталог услуг с подробным описанием
- Фотографии примеров работ
- Возможность заявки на услугу

### Пользователи и личный кабинет

- Регистрация и авторизация пользователей
- Личный профиль с возможностью редактирования
- Подтверждение email
- История заказов
- Сохранение адресов доставки

## Инструкция по работе с админ-панелью

### Вход в админ-панель

1. Перейдите по адресу http://ваш_домен/management-stroyma-7x4/ (или по пути из `ADMIN_URL`)
2. Введите логин и пароль администратора

### Управление товарами

#### Добавление нового товара:

1. В меню выберите "Товары" > "Добавить"
2. Заполните следующие поля:
   - Название товара
   - URL-имя (генерируется автоматически, но можно изменить)
   - Описание
   - Цена
   - Количество на складе
   - Рейтинг (от 1 до 5)
   - Изображение
   - Категории (можно выбрать несколько)
   - SEO информация (заголовок, описание, ключевые слова)
3. Нажмите "Сохранить"

Чтобы скрыть товар без удаления, снимите флажок «Показывать на сайте» в его карточке. В списке товаров можно выбрать несколько строк и применить действие «Скрыть выбранные товары с сайта». Скрытый товар исчезнет из каталога, поиска, корзины и карты сайта; история заказов сохранится. Действие «Показать выбранные товары на сайте» вернёт товары в продажу.

### Пользователи и роли

Суперпользователь открывает раздел «Роли и права», создаёт группу и отмечает только нужные разрешения, например просмотр и изменение товаров или заказов. Затем в разделе «Пользователи» он открывает сотрудника, включает «Статус персонала» и назначает группу. Флажок «Статус суперпользователя» менеджеру не требуется. Менеджер с разрешением на изменение пользователей может редактировать данные покупателей, но не может менять права сотрудников или состав ролей.

#### Добавление дополнительных изображений товара:

1. На странице редактирования товара прокрутите вниз до раздела "Изображения товара"
2. Нажмите "Добавить еще одно Изображение для..."
3. Загрузите изображение, при желании добавьте название и порядок отображения
4. Нажмите "Сохранить"

#### Управление категориями товаров:

1. В админ-панели выберите "Категории"
2. Для добавления новой категории нажмите "Добавить категорию"
3. Заполните название, URL-имя и выберите родительскую категорию (если это подкатегория)
4. Для перемещения категорий используйте drag-and-drop интерфейс на странице списка категорий

### Управление заказами

#### Просмотр и редактирование заказов:

1. В меню выберите "Заказы"
2. Для просмотра деталей заказа кликните на номер заказа
3. На странице заказа вы увидите:
   - Информацию о пользователе
   - Список товаров с количеством и суммой
   - Общую стоимость заказа
   - Историю статусов заказа

#### Изменение статуса заказа:

1. Откройте заказ для редактирования
2. В поле "Статус" выберите один из вариантов:
   - В ожидании (pending)
   - Обработка (processing)
   - Доставляется (shipped)
   - Завершен (completed)
   - Отменен (canceled)
3. Нажмите "Сохранить"

При изменении статуса заказа автоматически создается запись в истории статусов.

#### Экспорт заказов:

На странице списка заказов вы можете:
1. Выбрать заказы, установив флажки
2. В выпадающем меню "Действие" выбрать:
   - "Экспорт в CSV" для получения табличного формата
   - "Экспорт в PDF" для более форматированного отчета

### Аналитика и отчеты

1. В меню выберите "Аналитика" > "Отчет по продажам"
2. На странице отчета вы увидите:
   - График продаж за выбранный период (день, неделя, месяц)
   - Статистику по количеству заказов и общей сумме
   - Популярные товары
   - Статистику по статусам заказов

Используйте фильтры для изменения периода и получения более детальной информации.

### Управление услугами

#### Добавление услуги:

1. В меню выберите "Услуги" > "Добавить"
2. Заполните информацию:
   - Название услуги
   - Краткое и подробное описание
   - Загрузите изображение/иконку
   - Укажите преимущества (по одному на строку)
   - Заполните SEO информацию
3. Нажмите "Сохранить"

#### Добавление фотографий к услуге:

1. На странице редактирования услуги прокрутите до раздела фотографий
2. Нажмите "Добавить еще одно Фото услуги"
3. Загрузите фотографию, укажите название, описание и порядок отображения
4. Нажмите "Сохранить"

### Работа с клиентами

#### Просмотр информации о клиентах:

1. В меню выберите "Профили пользователей"
2. В списке показана основная информация о пользователях
3. Кликните на профиль для просмотра подробной информации

#### Поиск клиента:

1. В верхней части админ-панели есть поле поиска
2. Введите имя пользователя, email или телефон
3. В результатах поиска выберите нужного клиента

#### Просмотр заказов клиента:

1. Откройте профиль клиента
2. В разделе "История заказов" будут показаны все заказы пользователя
3. Кликните на номер заказа для перехода к подробной информации

## Дополнительная информация

### Рекомендации по SEO-оптимизации

- Всегда заполняйте поля "SEO заголовок" и "SEO описание" для категорий, товаров и услуг
- Используйте ключевые слова в названиях и описаниях
- Добавляйте альтернативный текст к изображениям

### Управление цветами и текстурами

Система поддерживает управление цветами и текстурами для фасадов:
1. В меню выберите "Цвета фасадов" или "Базовые текстуры"
2. Добавьте новые цвета с кодом HEX или загрузите текстуры
3. Эти параметры можно будет использовать при создании товаров

### Оптимизация производительности

- Система использует кеширование для популярных товаров и аналитики
- Для больших каталогов рекомендуется настроить дополнительный кеш (Redis/Memcached)
- Регулярно проверяйте наличие индексов в базе данных для часто используемых запросов

## Устранение неполадок

### Проблемы с загрузкой изображений

1. Проверьте права доступа к директории media/
2. Убедитесь, что в настройках правильно указаны MEDIA_URL и MEDIA_ROOT

### Ошибки в работе с базой данных

1. Проверьте подключение к базе данных
2. Убедитесь, что все миграции применены
3. Выполните команду `python manage.py check` для проверки ошибок в моделях

### Проблемы с отправкой email

1. Проверьте настройки SMTP в файле settings.py
2. Убедитесь, что указаны правильные учетные данные для почтового сервера
