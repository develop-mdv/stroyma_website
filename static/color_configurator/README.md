# Локальный 3D-конфигуратор фасада

Геометрия дома и участка, а также текстуры генерируются локально в JavaScript. Файлов изображений текстур и ссылок на них нет: карты штукатурки, цоколя, земли и неба создаёт `src/textures.js` в браузере. Виджет не запрашивает ресурсы с исходного сайта и не зависит от его доступности. Во встроенном режиме кнопка заявки открывает форму на `/color-selection/`; при открытии виджета отдельной ссылкой она ведёт на ту же форму с сохранением выбранной отделки. Подпись на скачиваемом PNG «СтройМа».

В `vendor/three` находится Three.js r169, распространяемый по лицензии MIT; см. `vendor/three/LICENSE`.

При следующем изменении модулей поднимайте версии в `index.html`, импортах `app.js` и параметре `v` в `products/views.py`: на продакшене JavaScript кешируется на 30 дней. HTML виджета отдаётся с `Cache-Control: no-cache`. Nginx сжимает текстовые файлы gzip.
