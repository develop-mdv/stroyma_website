# Локальный 3D-конфигуратор фасада

Геометрия дома и участка, а также текстуры генерируются в JavaScript. Виджет не запрашивает ресурсы с исходного сайта. Кнопка заявки посылает сообщение странице `/color-selection/`, которая показывает форму СтройМа. Подпись на скачиваемом PNG «СтройМа».

В `vendor/three` находится Three.js r169, распространяемый по лицензии MIT; см. `vendor/three/LICENSE`.

При следующем изменении модулей поднимайте версии в `index.html`, импортах `app.js` и параметре `v` в `products/views.py`: на продакшене JavaScript кешируется на 30 дней. HTML виджета отдаётся с `Cache-Control: no-cache`. Nginx сжимает текстовые файлы gzip.
