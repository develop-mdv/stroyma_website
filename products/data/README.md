# Каталог из выгрузок 29.09.2026

`catalog_2026_09_29.json` — зафиксированное сопоставление 135 строк файла
`Остатки на склад 2.xlsx` с 123 строками файла `прайс.xls`.
Для количества взят столбец «Конечный остаток», для цены — столбец «Опт».
Два отрицательных остатка в выгрузке приведены к нулю. Цены 12 товаров,
отсутствующих в прайсе, представлены нулём как служебным значением: на сайте
показывается «Цена уточняется», заказ таких товаров заблокирован.

Фотографии в `photos/` сохранены для 65 позиций, у которых найдены
совпадающие модель, фасовка и цвет. Страницы источников и адреса изображений
записаны в `catalog_photo_sources.json` и рядом с товарами в снимке каталога.
Для остальных 70 позиций в `illustrations/` подготовлены отдельные
схематичные изображения с точным названием из выгрузки и явной пометкой
«Иллюстрация». Это не фотографии упаковки. Фото и иллюстрации созданы
из исходных данных и локально хранятся в WebP, поэтому каждая карточка
имеет изображение, даже если внешний сайт позднее удалит оригинал.

Перед публичным использованием фотографий подтвердите разрешение правообладателя: запись страницы источника не заменяет лицензию. Импорт не подтверждает юридическую полноту карточки. Сведения об изготовителе, месте изготовления, безопасности и сроках заполняются в новых полях товара по упаковке и документации. Цены из столбца «Опт» и единицы продажи нужно сверить с фактическими розничными условиями. Проверка пустых полей: `python manage.py audit_legal_readiness`.

Повторно подготовить снимок, загрузить проверенные фотографии и построить
иллюстрации:

```powershell
python tools/build_catalog_fixture.py
python tools/download_catalog_photos.py
python tools/generate_catalog_illustrations.py
```

Загрузить снимок в базу:

```powershell
python manage.py migrate
python manage.py import_catalog_snapshot
python manage.py import_catalog_snapshot --apply
```

Команда повторного импорта обновляет описание, цену, единицу измерения и
недостающие изображения, сохраняя текущие складские остатки и существующие
товары вне выгрузки. `--reset-stocks` следует использовать только при
сознательной переустановке остатков на дату выгрузки.
